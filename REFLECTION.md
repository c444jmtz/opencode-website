# DS219 Assignment 5 — Reflection

## Project

I built Stereo Angel, a one-page music website using OpenCode. It features my favorite albums by Phoebe Bridgers, Hole, and Lana Del Rey, as well as genre-filtered song recommendations and links to Spotify. I designed the website around a black-and-white DIY punk flyer aesthetic, using distressed typography, vinyl-inspired album displays, and a grungy layout.

## AI Model

I initially used OpenCode with CatJam, which identified itself as a model from LitterBox AI. After experiencing connection issues, I connected my ChatGPT account and continued working on the website through OpenCode.

## Tool Action Observed

I observed OpenCode inspect and modify my website files, including `index.html`, `style.css`, and `script.js`, to implement changes I requested. For example, OpenCode modified the recommendation data in `script.js` after I pointed out inaccuracies in the song titles and genre classifications. It explained which files were modified and what changes it made.

## Example Prompt Used

One prompt I gave OpenCode was:

"Please inspect the recommendation data in `script.js` and correct it. Replace incorrect entries with real songs by the correct artists. Verify song titles, artists, and genre classifications before editing. Preserve the existing website appearance, album section, logo, mobile layout, and genre filtering. Do not commit or push anything."

I used this prompt to correct inaccurate recommendations without affecting the rest of my website.
